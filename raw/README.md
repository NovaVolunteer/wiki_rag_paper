# raw/

Immutable. Whatever comes in — a meeting transcript, an RFI, a schema, a plan — gets saved here exactly as received, named `YYYY-MM-DD-short-description.ext`. Never edited, never deleted, never summarized in place.

This is the paper trail behind the wiki. If a `wiki/` page ever looks wrong, this is where to check what it was actually built from.

Subfolders: `meetings/`, `rfis/`, `schemas/`, `plans/`.
